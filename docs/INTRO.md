# EARSHOT

**用声呐在黑暗里逃生，而不是杀出一条路。**

EARSHOT 是一款把声音同时当作视野与仇恨的黑暗逃生肉鸽。没有灯，没有小地图，也没有站在明处的敌人；你发出一次脉冲，墙壁、门和猎手在黑暗里显形一瞬，同一道声波也把你的位置送了出去。看见，就等于被听见。

核心机制只有一条：脉冲是唯一的信息来源，也是最大的代价。你可以用一次脉冲读墙、读距离、判断猎手方位，也可以选择沉默摸黑，靠回声和脚步猜门后的结构。每一次发声都是一次下注——知道得越多，追你的人也越清楚你在哪。

一局从“房间”开始，之后地图分叉：不同的门通往不同区域，路线、钥匙、猎手和机关每局重新组合，传送门只向前，不能回头。目标不是清场，而是在被围住之前找到下一道门。死亡会重置这一局；你带不走等级和装备，只能带走对声音的理解。

灵感来自肉鸽，但成长不靠杀敌。你变强，是因为更会读空间、更会控制什么时候发声。分支的终点是 Boss——例如猫笼：一只只在你观测时回应、朝你最后一次发声位置走来的猫。它没有血条，也不会站在原地和你换血；它考的是你能不能在“必须看”和“不能出声”之间做对选择。

声音是唯一的眼睛，安静是唯一的武器。
